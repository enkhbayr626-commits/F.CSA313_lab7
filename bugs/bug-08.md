# BUG-08: Он баганад оныг мянгатын таслалтай харуулж байна

Орчин: Уншлагын жагсаалт v2.0; WSL2 Ubuntu, Node.js v18.19.1; Windows Firefox 158.0; 2026-10-20.

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асааж, Firefox-д `http://localhost:3000` нээсэн; анхны 3 номтой. Өмнөх хайлт, нэмсэн өгөгдөлд тулгуурлахгүй.

## Дахин гаргах алхам

1. Анхны гурван номын Он баганыг харна.
2. Нэмэлт хувилбарт `Year Format / Enkhbayar / 2020` ном нэмээд оны дүрслэлийг харна.

Хүлээгдэж байсан: Он нь `1971`, `2008`, `1999`, `2020` гэх мэт энгийн бүхэл тоогоор харагдана.

Бодит үр дүн: Session-ийн зургууд дээр анхны онууд `1,971`, `2,008`, `1,999`, нэмсэн номын он `2,020` гэж харагдсан.

Ноцтой байдал: Cosmetic — оны дүрслэл заавартай зөрсөн.

Олдсон аялал: Supermodel.

Энэ тайлан оны форматын тухай; он дутуу байхад 0 болсон оролтын алдааг BUG-01-д тусад нь оруулсан.

Баталгаажуулалт: 2026-10-20-нд шинэ clone-ийн аппыг дахин асааж, Chromium суурьтай апп доторх браузераар зөрчлийг давтан шалгасан. Session-ийн эх зураг нь Firefox-ийнх; доорх recheck зургууд тусдаа.

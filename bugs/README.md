UI зургууд нь С. Энхбаярын session-ийн нотолгоо. UI-ийн алхмуудыг зурган дахь оролт, үйлдлээс бичсэн; Firefox-ийн автомат дахин шалгалт browser URL policy дэмжигдээгүйгээс зогссон. API-ийн BUG-10, BUG-11-ийг шинээр асаасан апп дээр WSL curl-аар тус бүр дахин баталж, evidence/recheck/ дотор гаралтыг хадгалсан. BUG-06-ийг давтагдсан гэж тооцохгүй; BUG-07-ийн яг уртыг дахин хэмжих шаардлагатай.

Тайлан бүр шинэ сервер, анхны 3 номтой төлөвөөс эхлэх нөхцөлтэй. Session-ийн зурагт өмнөх туршилтын нэмэлт мөрүүд байж болно. Аяллын харьяаллыг charter болон үйлдлийн төрлөөр ангилсан; эх кодоос шалтгаан тогтоогоогүй. Эх тэмдэглэл, өмнөх screenshots болон curl файлуудыг өөрчлөөгүй.
